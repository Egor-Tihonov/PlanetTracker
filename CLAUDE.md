# PlanetTracker: правила для Claude

Карманная карта неба на ESP32-C3. Описание проекта в README.md.

## Память проекта: папка .claude/
- `.claude/progress.md` — что делаем сейчас, принятые решения, журнал обсуждений.
- `.claude/astro-notes.md` — шпаргалка по математике эфемерид и источникам данных.
- `.claude/workflow.md` — как работаем: этапы, проверки, команды.

В начале сессии прочитать `progress.md`. В конце сессии или после важного
решения дописать в него 1-3 строки. Папку держать маленькой: не дублировать
README и код, не хранить логи, старые записи журнала сжимать.

## Стиль
- Объяснения простыми словами, без формул, если пользователь не просит формулы.
- Обсуждаем пошагово: пользователь задаёт вопросы по шагу, потом идём дальше.
- Ветка main только через PR. Push только по явной просьбе.
